# Phase 0 対応・制限・拒否一覧

検証日: 2026-09-11。Chromium 152、固定fixtureで確認。対応は任意のMarkdown構文全体を保証する意味ではない。

| 対象 | 分類 | 確認結果・制限 |
|---|---|---|
| 日本語＋英数字 | 対応 | turn-a [9,18)。「日本語ABC123」 |
| 同一Turnの同じ語 | 対応 | 2番目の「確認」は[29,31)。最初の語へ移動しない |
| 別Turnの同文 | 対応 | turn-b [9,18)。turn-aと独立 |
| 絵文字 | 対応 | 😀は2 UTF-16単位。途中切断拒否 |
| ZWJ絵文字 | 対応 | 家族絵文字全体11 UTF-16単位 |
| 結合文字 | 対応 | e＋アクセント、か＋濁点。全体を選択 |
| 見出し | 対応 | 見出し本文内の範囲。先頭の#は含めない |
| 通常段落 | 対応 | 同一ブロック・テキストノード境界の選択 |
| リスト | 制限付き | 単純な1項目内で確認。項目をまたぐ選択は拒否 |
| 太字 | 制限付き | 全体・一部・前後通常文への連続選択を確認。外側の**を自動包含しない |
| リンク | 制限付き | ラベル全体・一部で確認。選択端をURLへ拡張しない。PoCではリンク遷移を無効化 |
| インラインコード | 制限付き | 原文に表示文字列が一意一致するときだけfallback。単純なcode_123を確認。正規化等で一致しないものは拒否 |
| コードブロック | 拒否 | pre内は原文位置付与対象外 |
| 複数段落 | 拒否 | 同一Turnでもブロック横断は禁止 |
| 表 | 拒否 | table内は対象外 |
| Markdownエスケープ | 拒否 | 表示と原文が一致しないテキストノードをマップしない |
| 文字参照 | 拒否 | &amp;→&等。同じノード内の普通の文字も選択不可になり得る |
| 未対応文字を途中に含む選択 | 拒否 | 両端がマップ可能でも、中間が未対応なら拒否 |
| 逆方向ドラッグ | 対応 | Selection方向に依存せず原文はstart<end。実ドラッグでも確認 |
| Turnまたぎ | 拒否 | 同じ本文があってもTurnを混同しない |
| 生成中・user発言 | 拒否 | マーカー取得・登録不可 |
| 重複／包含／完全一致 | 拒否 | 既存マーカーを消したように見せず、登録前に拒否 |
| 隣接 | 対応 | [a,b)と[b,c)を別マーカーとして描画 |
| 要素境界のSelection | 拒否 | Rangeの両端がTextノードでない選択は対象外 |
| 空白だけの選択 | 拒否 | 登録対象の引用がないため |
| 保存→再読込 | 対応 | JSON往復、4色・メモ・複数Turnを確認 |
| ページ再読込→保存読込 | 対応 | localStorageを明示読込して青マーカー・メモを復元 |
| 表示幅変更後の復元 | 対応 | fixture幅900→360、実UI幅切替後のジャンプを確認 |
| source_text不一致 | unresolved | 描画・ジャンプ不可。元位置を保持、推測修復しない |

Phase 0で対応を約束しないもの: 任意のネスト構文、脚注、数式、HTML、画像、コードのシンタックスハイライト、仮想スクロール、Safari/Firefox、モバイルのタッチ選択、スクリーンリーダーによる範囲選択。これらを暗黙に対応済みとはしない。
