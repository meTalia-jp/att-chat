# Phase 2A Markdown対応・制限・拒否一覧

Phase 0の分類を維持する。Phase 2Aでは、completed Assistant Turnかつ以下の安全に原文へ対応付けられる範囲だけを登録する。「対応」は任意のMarkdown全体を保証する意味ではない。

| 対象 | 分類 | Phase 2Aの扱い |
|---|---|---|
| 日本語＋英数字 | 対応 | UTF-16 offsetで原文範囲へ変換 |
| 同一Turnの同じ語 | 対応 | 文字検索せずDOM位置から変換し、選んだ出現位置を保持 |
| 別Turnの同文 | 対応 | turn_idで独立 |
| 絵文字、ZWJ絵文字、結合文字 | 対応 | grapheme全体のみ。途中境界は拒否 |
| 見出し、通常段落 | 対応 | 同一block内で表示文字と原文位置が対応する範囲 |
| リスト | 制限付き | 単一項目内。項目横断は拒否 |
| 太字 | 制限付き | 対応できるテキスト範囲。Markdown記号を自動包含しない |
| リンク | 制限付き | ラベル文字の対応範囲。リンク遷移は無効化 |
| インラインコード | 制限付き | 表示文字列が原文内で一意に対応するときだけ位置付与 |
| コードブロック | 拒否 | `pre`内に位置情報を付与しない |
| 複数段落・block横断 | 拒否 | 同一Turnでも拒否 |
| 表 | 拒否 | `table`内に位置情報を付与しない |
| Markdownエスケープ、文字参照 | 拒否 | 表示と原文が一対一にならないnodeは位置を付与しない |
| 未対応文字を途中に含む範囲 | 拒否 | 両端が対応していても範囲内を検査して拒否 |
| 逆方向ドラッグ | 対応 | Rangeの正規化済みstart/endを使う |
| Turnまたぎ | 拒否 | 同じTurn要素内でなければ拒否 |
| User、generating、cancelled、failed | 拒否 | 選択位置を付与しない。Repositoryでも再検証 |
| 重複、包含、完全一致 | 拒否 | API/Repository/DBで拒否 |
| 隣接 | 対応 | `[a,b)` と `[b,c)` を独立保存・描画 |
| 要素境界、空白だけ | 拒否 | 正確な原文変換または引用表示が成立しないため拒否 |
| source_text不一致 | unresolved | 元位置を保持し、描画と自動修復を行わない |

任意のネスト構文、脚注、数式、HTML、画像、コードのシンタックスハイライト、仮想スクロールは対応を約束しない。Phase 0で未検証だったブラウザ・入力手段もPhase 2Aで対応済みとは扱わない。
